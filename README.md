# patient-no-show_analysis

Business Problem:

Missed medical appointments waste healthcare resources and disrupt patient care. This project analyzes appointment data to identify factors associated with no-shows and help healthcare providers develop strategies to improve attendance and reduce missed appointments.

Data & Tools:
Dataset: Medical Appointment No Shows, CC BY-NC-SA 4.0 — Kaggle
https://www.kaggle.com/datasets/joniarroba/noshowappointments

Tools: MySQL

Techniques Used:
Data Cleaning and Date Conversion
Conditional Logic (CASE WHEN)
Aggregations (COUNT, SUM, ROUND)
Grouping and Filtering (GROUP BY, HAVING)
Window Functions (RANK, COUNT OVER, SUM OVER)
Common Table Expressions (CTEs)
Views and Patient-Level Risk Classification
